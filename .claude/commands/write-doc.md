Write or update a human doc about: $ARGUMENTS

Rules:
- File in `docs/`, lowercase name with dashes, e.g. `docs/flashing-the-board.md`
- Start with one sentence saying what the doc is for
- Bullet points and numbered steps; short sentences
- Only what a person needs to do or understand; no background they did not ask for
- No tables or diagrams unless they explain more than text can; at most one diagram
- A small CSV block is fine for data that is easier to scan that way
- Link to other docs instead of repeating them
- Add a link to the new doc in README.md under "Documentation"
